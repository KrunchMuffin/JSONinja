## Baalda project notes
When working on any of my projects, use the `baalda` MCP server: read the vault's root `AGENTS.md`, then `Projects/AGENTS.md`, then that project's main note before starting. Follow its rules for tasks, ideas and facts.

- You may create new documents when the work needs them (specs, research, plans, drafts). Put them in the project's folder, `Projects/<Area>/<Project>/`, and list each one under `## Files` in the project's main note. Search first so you don't duplicate an existing document.
- If the project has no folder yet, create the folder and its main note following the rules in `Projects/AGENTS.md`, and add the project to the index tables.
- Tasks and log lines only ever go in the project's main note, never in supporting documents.
- Before you finish, append one log line to the project's main note, including any documents you created.
